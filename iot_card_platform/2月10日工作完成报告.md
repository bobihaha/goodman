2. 记录成功创建的卡片ID和ICCID

4. 批量创建卡片关联记录
5. 提交事务

**代码示例**：
```python
# 创建新表记录（stock_in_records）
new_record_sql = """
    INSERT INTO stock_in_records 
    (supplier_id, package_id, test_expire_date, silent_expire_date, 
     card_count, success_count, failed_count, remark, operator_id, created_at, updated_at)
    VALUES 
    (:supplier_id, :package_id, :test_expire_date, :silent_expire_date,
     :card_count, :success_count, :failed_count, :remark, :operator_id, NOW(), NOW())
"""

# 创建卡片关联记录
for card_info in created_card_ids:
    relation = StockInRecordCardModel(
        record_id=new_record_id,
        card_id=card_info["card_id"],
        iccid=card_info["iccid"]
    )
    db.add(relation)
```

**效果**：
- ✅ 每次入库操作都会自动记录到新表

**实现流程**：

3. 计算单价和总金额（元转分）
4. 使用原始SQL插入新表记录
5. 批量创建卡片关联记录
6. 提交事务

**代码示例**：
```python
# 获取销售套餐价格信息（价格单位：元，需要转换为分）
sale_package_query = text("SELECT price_sale FROM sale_packages WHERE id = :package_id")
sale_package_result = await db.execute(sale_package_query, {"package_id": sale_package_id})
sale_package_row = sale_package_result.fetchone()
unit_price = int(sale_package_row.price_sale * 100) if sale_package_row and sale_package_row.price_sale else 0
total_amount = unit_price * success_count

# 创建新表记录（stock_out_records）
new_record_sql = """
    INSERT INTO stock_out_records 
    (user_id, sale_package_id, card_count, success_count, failed_count, 
     unit_price, total_amount, remark, operator_id, created_at, updated_at)
    VALUES 
    (:user_id, :sale_package_id, :card_count, :success_count, :failed_count,
     :unit_price, :total_amount, :remark, :operator_id, NOW(), NOW())
"""
```

**效果**：

### 5. Bug修复

#### 问题1：模型表名冲突

**问题描述**：
- 旧表 `stock_in_records_old` 和 `stock_out_records_old` 不存在
- 导致ORM操作失败

**解决方案**：
- 修改模型表名为 `stock_in_records_old_backup` 和 `stock_out_records_old_backup`

**修改文件**：`app/db/models/stock.py`

```python
class StockInRecordModel(BaseModel):
    """入库记录模型（旧版-批次入库）"""
    __tablename__ = "stock_in_records_old_backup"

class StockOutRecordModel(BaseModel):
    """出库记录模型（旧版-批次出库）"""
    __tablename__ = "stock_out_records_old_backup"
```

---

#### 问题2：BusinessException参数名错误

**问题描述**：
- 代码中使用了 `BusinessException(code=xxx, message="xxx")`
- 但实际参数名应该是 `msg` 而不是 `message`
- 导致异常抛出失败

**解决方案**：
- 批量修复所有 `BusinessException` 的参数名
- 使用 `sed` 命令批量替换：`message=` → `msg=`

**影响范围**：
- `app/services/stock_service.py`
- `app/services/iot_card_service.py`
- `app/services/sync_service.py`
- `app/services/pool_service.py`

**修复命令**：
```bash
find app/services -name "*.py" -exec sed -i '' 's/BusinessException(code=\([0-9]*\), message=/BusinessException(code=\1, msg=/g' {} \;
```

---

#### 问题3：出库操作查询销售套餐价格字段错误

**问题描述**：
- SQL查询使用了 `unit_price` 字段
- 但 `sale_packages` 表中实际字段名为 `price_sale`
- 导致SQL查询失败

**解决方案**：
- 修改SQL查询字段名为 `price_sale`
- 添加价格单位转换逻辑（元 → 分）

**修改文件**：`app/crud/stock_crud.py`

```python
# 修改前
sale_package_query = text("SELECT unit_price FROM sale_packages WHERE id = :package_id")
unit_price = sale_package_row.unit_price if sale_package_row else 0

# 修改后
sale_package_query = text("SELECT price_sale FROM sale_packages WHERE id = :package_id")
unit_price = int(sale_package_row.price_sale * 100) if sale_package_row and sale_package_row.price_sale else 0
```

## 🔧 技术亮点

### 1. 双表记录机制
- 保留旧表（`*_old_backup`）用于兼容性
- 新表（`stock_in_records`、`stock_out_records`）提供更完善的功能
- 入库/出库操作同时写入两套表，确保平滑过渡

### 2. 卡片关联追溯
- 通过关联表（`*_record_cards`）建立记录与卡片的多对多关系
- 支持查询每条记录涉及的所有卡片
- 支持反向查询每张卡片的入库/出库历史

### 3. 财务数据自动计算
- 出库时自动查询销售套餐价格
- 自动计算单价和总金额
- 价格单位统一（数据库存储为分，前端显示为元）

### 4. 高效的SQL查询
- 使用 LEFT JOIN 一次性获取关联数据
- 避免N+1查询问题
- 支持大量卡片的高效查询
