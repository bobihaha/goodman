# ICCID字段类型修复记录

**时间**：2026年2月10日  
**问题**：ICCID验证规则只允许数字，但实际ICCID可能包含字母

---

## 🐛 问题描述

### 原有限制
前端代码中ICCID的验证规则为：
```javascript
/^\d{19,20}$/  // 只允许19-20位纯数字
```

### 实际情况
ICCID（Integrated Circuit Card Identifier）是物联网卡的唯一标识符，格式为：
- **长度**：通常为19-20位
- **字符**：可以包含数字（0-9）和字母（A-Z，不区分大小写）
- **示例**：
  - `89860123456789012345` （纯数字）
  - `8986012345678901234A` （数字+字母）
  - `89860ABC456789012345` （混合）

## 📋 新的验证规则

### 正则表达式
```javascript
/^[0-9A-Za-z]{19,20}$/
```

### 规则说明
- **字符集**：`[0-9A-Za-z]` - 数字0-9和字母A-Z（不区分大小写）
- **长度**：`{19,20}` - 19位或20位
- **完全匹配**：`^...$` - 必须完全匹配，不允许其他字符

### 有效示例
- ✅ `89860123456789012345` - 20位纯数字
- ✅ `8986012345678901234` - 19位纯数字
- ✅ `8986012345678901234A` - 19位数字+1位字母
- ✅ `89860ABC456789012345` - 混合字母和数字
- ✅ `89860abc456789012345` - 小写字母也可以

### 无效示例
- ❌ `898601234567890123` - 只有18位（太短）
- ❌ `898601234567890123456` - 21位（太长）
- ❌ `8986012345678901234-` - 包含特殊字符
- ❌ `8986 0123 4567 8901 234` - 包含空格

## 🔍 ICCID格式说明

### 标准格式
ICCID遵循 ITU-T E.118 标准，通常格式为：

```
89 CC II SSSSSSSSSS C
```

- **89**：固定前缀（电信行业标识）
- **CC**：国家代码（如中国为86）
- **II**：发行商标识
- **SSSSSSSSSS**：序列号
- **C**：校验位（可选）

### 中国运营商示例
- **中国移动**：`898600` 或 `898602` 开头
- **中国联通**：`898601` 开头
- **中国电信**：`898603` 开头
