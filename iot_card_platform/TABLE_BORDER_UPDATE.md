### 与 `stripe` 属性配合

所有表格同时使用了 `stripe` 和 `border` 属性：
- `stripe`: 斑马纹效果，奇偶行背景色不同
- `border`: 网格线效果，单元格之间有边框

两者配合使用，既有清晰的分隔线，又有舒适的视觉层次。

## Element Plus 表格属性说明

### border 属性
```vue
<el-table border>
```
- **类型**: Boolean
- **默认值**: false
- **说明**: 是否带有纵向边框
- **效果**: 显示完整的表格网格线

### stripe 属性
```vue
<el-table stripe>
```
- **类型**: Boolean
- **默认值**: false
- **说明**: 是否为斑马纹表格
- **效果**: 奇偶行背景色不同

### 推荐组合
```vue
<el-table border stripe>
```
这是最常用的组合，既有网格线又有斑马纹，视觉效果最佳。

## 注意事项

1. **固定列**: 如果表格有固定列（`fixed`），网格线会自动适配
2. **合并单元格**: 如果使用了 `span-method`，网格线会正确显示
3. **自定义样式**: 可以通过CSS覆盖默认的边框样式

## 自定义边框样式（可选）

如果需要自定义边框颜色或粗细，可以添加以下样式：

```scss
::v-deep .el-table {
  // 自定义边框颜色
  --el-table-border-color: #e4e7ed;
  
  // 自定义边框粗细
  border-width: 1px;
  
  td, th {
    border-color: #e4e7ed;
  }
}
```
