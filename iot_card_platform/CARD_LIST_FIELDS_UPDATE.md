### 2. 流量使用率显示优化

#### 修改前
- 显示格式：`1.5GB / 2GB`
- 进度条百分比：小数（如 75.5%）

#### 修改后
- 显示格式：`1.5GB / 2GB (75%)`
- 进度条百分比：整数（如 75%）
- 百分比精确到整数，使用四舍五入

#### 实现方式
```typescript
// 格式化流量使用率为整数
const formatUsagePercentInt = (used: number, total: number): number => {
  if (!total || total <= 0) return 0
  const percent = (used / total) * 100
  return Math.round(Math.min(Math.max(percent, 0), 100))
}
```

### 3. 字段说明

#### 3.1 出库日期 (stock_out_at)
- **含义**：卡片从库存出库的时间
- **格式**：ISO格式（如：2026-02-10T10:30:00）
- **显示**：使用 `formatDateShort` 转换为短日期格式
- **空值处理**：显示为空

#### 3.2 测试期到期 (test_expire_date)
- **含义**：卡片测试期的到期日期
- **格式**：26/1/31（年/月/日，年份只显示后两位）
- **显示**：直接显示后端返回的格式化值
- **空值处理**：显示 `-`

#### 3.3 沉默期到期 (silent_expire_date)
- **含义**：卡片沉默期的到期日期
- **格式**：26/1/31（年/月/日，年份只显示后两位）
- **显示**：直接显示后端返回的格式化值
- **空值处理**：显示 `-`

#### 3.4 激活日期 (activated_at)
- **含义**：卡片激活的日期
- **格式**：26/1/31（年/月/日，年份只显示后两位）
- **显示**：直接显示后端返回的格式化值
- **空值处理**：显示 `-`

#### 3.5 到期日期 (expired_at)
- **含义**：卡片套餐的到期日期
- **格式**：26/1/31（年/月/日，年份只显示后两位）
- **显示**：直接显示后端返回的格式化值
- **特殊样式**：如果已过期，显示为红色
- **空值处理**：显示 `-`
