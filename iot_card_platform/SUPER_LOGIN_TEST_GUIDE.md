# 超级登录功能测试指南

## 🔧 问题修复

### 问题
前端调用超级登录API时出现500错误：
```
Unknown column 'is_deleted' in 'field list'
```

### 原因
`SuperLoginLogModel` 继承自 `BaseModel`，自动包含了 `is_deleted` 字段，但数据库表创建时没有包含此字段。

### 解决方案
```sql
ALTER TABLE sys_super_login_logs 
ADD COLUMN is_deleted TINYINT DEFAULT 0 
COMMENT '删除标记：0=未删除，1=已删除';
```

✅ 已执行完成

## 🔍 数据库验证

### 查看超级登录日志
```sql
SELECT 
    id,
    original_user_id,
    target_user_id,
    login_at,
    logout_at,
    ip,
    LEFT(user_agent, 50) as user_agent_short,
    created_at
FROM sys_super_login_logs
ORDER BY login_at DESC
LIMIT 10;
```

### 预期结果
- 每次超级登录都会创建一条记录
- `login_at` 记录登录时间
- `logout_at` 在退出时更新
- `original_user_id` 是原用户ID（如：1）
- `target_user_id` 是目标用户ID（如：2）

## 🐛 常见问题排查

### 问题1：看不到"超级登录"按钮
**原因**：
- 当前用户没有权限
- 目标用户不是下级用户

**检查**：
```javascript
// 超级管理员 (user_level = 1) 只能登录到普通用户 (user_level = 2)
// 普通用户 (user_level = 2) 只能登录到自己的子用户 (user_level = 3)
```

### 问题2：超级登录失败
**可能原因**：
1. 目标用户已被禁用
2. 目标用户不存在
3. 没有上下级关系

**检查日志**：
```bash
tail -50 backend.log
```

### 问题3：横幅不显示
**检查**：
1. `authStore.isSuperLogin` 是否为 `true`
2. `MainLayout.vue` 是否正确导入 `SuperLoginBanner`
3. 浏览器控制台是否有错误

### 问题4：退出超级登录失败
**检查**：
1. Token是否有效
2. 后端 `/api/v1/auth/exit-super-login` 接口是否正常
3. 数据库连接是否正常
