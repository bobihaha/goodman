## 📊 数据流程

### 创建流量池流程
```
1. 用户填写流量池信息
   ↓
2. 前端验证（名称、运营商、流量大小、周期、阈值）
   ↓
3. 调用 createPool API
   ↓
4. 后端创建流量池记录
   ↓
5. 返回成功，刷新列表
```

### 添加卡片流程
```
1. 选择流量池
   ↓
2. 选择输入方式（ICCID输入 或 选择卡片）
   ↓
3. 如果选择卡片：
   - 自动筛选符合规格的卡片
   - 只显示已激活且未在池中的卡片
   ↓
4. 提交卡片ID或ICCID列表
   ↓
5. 后端验证并添加到流量池
   ↓
6. 更新流量池统计数据
   ↓
7. 返回成功，刷新数据
```

### 充值加油包流程
```
1. 选择流量池
   ↓
2. 获取可用加油包列表（按运营商筛选）
   ↓
3. 选择加油包
   ↓
4. 显示充值效果预览
   ↓
5. 二次确认
   ↓
6. 调用 rechargePool API
   ↓
7. 后端扣除账户余额
   ↓
8. 增加流量池总流量
   ↓
9. 记录充值日志
   ↓
10. 返回成功，刷新数据
```

## 📝 后端API要求

流量池模块需要后端提供以下API接口：

### 基础接口
- `GET /api/v1/pools` - 获取流量池列表
- `POST /api/v1/pools` - 创建流量池
- `GET /api/v1/pools/{id}` - 获取流量池详情
- `PUT /api/v1/pools/{id}` - 更新流量池
- `DELETE /api/v1/pools/{id}` - 删除流量池
- `PUT /api/v1/pools/{id}/status` - 启用/禁用流量池

### 统计接口
- `GET /api/v1/pools/stats` - 获取流量池统计

### 卡片管理接口
- `POST /api/v1/pools/{id}/cards` - 添加卡片到流量池
- `DELETE /api/v1/pools/{id}/cards` - 从流量池移除卡片
- `GET /api/v1/pools/{id}/cards` - 获取池内卡片列表

### 用量接口
- `GET /api/v1/pools/{id}/usage/trend` - 获取用量趋势

### 加油包接口
- `GET /api/v1/pools/packages` - 获取加油包列表
- `POST /api/v1/pools/{id}/recharge` - 充值加油包
- `GET /api/v1/pools/{id}/recharge-logs` - 获取充值记录

### 导出接口
- `POST /api/v1/pools/export` - 导出流量池列表
