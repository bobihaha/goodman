# 一期方案：后台补量与复机收口

## 目标

- 堵住“复机绕过停卡限制”的漏洞
- 支持上级用户给下级用户后台补量
- 补量后自动重检，满足条件时自动复机

## 一期范围

### 1. 统一复机规则

- 所有复机统一走停复机服务
- 普通复机不再允许直接把卡状态改成 `activated`
- 复机前必须校验停卡原因是否已解除

### 2. 复机规则

- `expired`
  - 不允许普通复机
  - 需要走续费流程
- `manual`
  - 不允许普通复机
  - 仅超级管理员可强制复机
- `card_exceed`
  - 只有单卡额度补足后才允许复机
- `pool_exceed`
  - 只有流量池额度补足、池不再超限后才允许复机

### 3. 后台补量

- 非流量池卡
  - 上级用户可给下级用户的单卡直接增加流量总量
  - 补量后自动重检该卡是否可复机
- 流量池
  - 上级用户可给下级用户的流量池增加池总量
  - 使用现有 `addon_flow` 字段存储叠加流量
  - 补量后自动重检该池下因 `pool_exceed` 停卡的卡

### 4. 权限

- 超级管理员
  - 可给任意用户卡片/流量池补量
  - 可强制复机
- 二级用户
  - 只能给直属下级用户的卡片/流量池补量
  - 不能强制解除人工停卡
- 三级用户
  - 不支持后台补量

## 一期接口

### 卡片

- `POST /api/v1/cards/batch/add-flow-by-iccids`
  - 通过 ICCID 批量给非流量池卡补量

### 流量池

- `POST /api/v1/pools/{pool_id}/recharge`
  - 给流量池增加叠加流量

## 说明

- 一期不做商品化、订单、支付
- 一期不支持下级用户自助购买流量
- 二期再扩展：
  - 非流量池卡流量购买
  - 流量池加油包购买
  - 到期续费购买
