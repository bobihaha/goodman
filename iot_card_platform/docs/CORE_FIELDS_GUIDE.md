# 核心字段清单

这份文档用于帮助维护者从“数据字段”视角理解系统，重点回答四个问题：

- 这个字段定义在哪里
- 谁会写它
- 谁会读它
- 改它时最容易影响哪些功能

这不是完整字段字典，而是覆盖当前项目里最核心、最容易联动出问题的一批字段。

## 1. 如何使用这份文档

遇到以下场景时，优先看这份清单：

- 新增数据库字段
- 修改字段含义
- 改接口返回字段
- 写迁移脚本
- 排查“列表和详情不一致”
- 排查“某个流程成功了但状态没更新”

建议顺序：

1. 先找到所属业务域
2. 确认字段定义位置
3. 检查写入方和消费方
4. 按“高风险联动”做回归

## 2. 全局规则

### 字段变更时至少同步检查

- `app/db/models/`
- `app/schemas/`
- `app/crud/`
- `app/services/`
- `app/api/v1/`
- `frontend/src/types/`
- `frontend/src/api/modules/`
- `frontend/src/views/`

### 最常见的漏改问题

- 数据库字段已经加了，但 schema 没加
- 后端返回了字段，但前端类型没补
- 列表接口改了，详情接口没改
- 主表改了，记录表的冗余字段没改
- 手工操作流程改了，同步/回调流程没同步

## 3. 卡片域

定义位置：

- `app/db/models/iot_card.py`

### 身份与归属字段

#### `iccid`

- 含义：卡片唯一标识
- 写入方：入库、同步、供应商相关流程
- 读取方：卡片列表、详情、搜索、停复机、回调、出入库记录、流量池
- 高风险联动：
  - 改动会影响卡片查询、回调匹配、停复机日志、导出

#### `iccid_suffix`

- 含义：ICCID 后 6 位，用于快速搜索
- 写入方：入库或修复脚本
- 读取方：卡片搜索、批量查询
- 高风险联动：
  - 若缺失会导致“后 6 位搜索”异常

#### `user_id`

- 含义：当前所属用户
- 写入方：出库、划拨、回收、部分修复脚本
- 读取方：权限过滤、卡片列表、项目归属、仪表盘统计
- 高风险联动：
  - 影响多租户可见范围
  - 影响卡片、项目、出入库和仪表盘统计口径

#### `supplier_id`

- 含义：卡片所属供应商
- 写入方：入库
- 读取方：同步任务、停复机供应商调用、供应商统计
- 高风险联动：
  - 影响同步任务和供应商 API 调用

#### `sale_package_id`

- 含义：卡片当前销售套餐
- 写入方：出库、续费、回收前置处理
- 读取方：卡片详情、出库记录、流量池组池依据、套餐展示
- 高风险联动：
  - 影响卡详情、出库、流量池规格判断

#### `project_id`

- 含义：卡片所属项目
- 写入方：出库、划拨或项目管理相关流程
- 读取方：项目筛选、卡片列表、项目统计
- 高风险联动：
  - 影响项目列表、卡片筛选和归属展示

### 规格字段

#### `carrier`

- 含义：运营商
- 写入方：入库、套餐派生
- 读取方：卡片列表、流量池组池、套餐展示、仪表盘
- 高风险联动：
  - 影响筛选、规格展示、池匹配

#### `flow_size`

- 含义：卡片套餐流量 MB 值
- 写入方：入库、套餐派生
- 读取方：卡片展示、流量池组池、统计计算
- 高风险联动：
  - 影响规格显示、组池、用量展示

#### `period_type`

- 含义：月包 / 年包
- 写入方：入库、套餐派生
- 读取方：卡片展示、流量池组池、生命周期逻辑
- 高风险联动：
  - 影响规格、过期计算、流量池匹配

#### `period_count`

- 含义：周期数量，例如 3 月、12 月、2 年
- 写入方：出库
- 读取方：卡片详情、出库记录、按卡号出入库查询、部分规格展示
- 高风险联动：
  - 这是卡片实例级成交快照，表示“这张卡出库时实际开了多久”
  - 不应该替代前端续费弹窗里的“续费月数”语义
  - 回收后重新出库时，如果记录表没有单独冗余周期快照，历史出库记录可能被当前值污染

### 套餐周期相关字段补充说明

#### `supplier_packages.period_months / period_days`

- 含义：底层套餐基础周期
- 作用：描述上游原始产品规格
- 读取方：底层套餐管理、入库记录、规格展示

#### `sale_packages.period_months / period_days`

- 含义：销售套餐基础周期
- 作用：描述销售套餐的默认月包/年包类型，不再作为“具体成交几个月”的唯一依据
- 读取方：销售套餐管理、规格展示、部分续费兜底逻辑
- 维护规则：
  - 销售套餐界面不再让用户手动输入套餐周期
  - 月包默认按 `1个月` 存储，年包按 `12个月/年` 业务口径计算
  - 具体开通时长以出库时选择的周期为准
  - 年包流量在套餐有效期内跨月累计，用完即按单卡超量停卡，不进入流量池

#### 周期字段治理结论

- `supplier_package` 负责“上游规格”
- `sale_package` 负责“销售规格”
- `iot_cards.period_count` 负责“这张卡实际成交周期”
- 续费页面里的“1个月/3个月/6个月/12个月”是用户本次续费时长，不应该再乘以 `period_count`

#### `card_type`

- 含义：单卡 / 流量池卡
- 写入方：组池、移池、入库默认值
- 读取方：卡片列表、流量池逻辑、停复机策略
- 高风险联动：
  - 影响单卡和池卡不同业务规则

### 生命周期字段

#### `test_expire_date`

- 含义：测试期到期日
- 写入方：入库、出入库记录冗余字段
- 读取方：卡片详情、库存、出入库记录
- 高风险联动：
  - 影响库存展示和生命周期说明

#### `silent_expire_date`

- 含义：沉默期到期日
- 写入方：入库、同步、修复脚本
- 读取方：卡片详情、库存、生命周期判断
- 高风险联动：
  - 影响库存和状态转换判断

#### `activated_at`

- 含义：激活日期
- 写入方：同步任务、供应商返回、修复脚本
- 读取方：卡片详情、生命周期显示、统计
- 高风险联动：
  - 影响状态流转、统计周期

#### `expired_at`

- 含义：套餐过期日
- 写入方：同步任务、续费流程、修复脚本
- 读取方：卡片状态、仪表盘到期卡、停复机策略
- 高风险联动：
  - 影响到期卡统计和自动停卡
  - 生命周期同步必须保护本地更长到期日，避免本地续费后被供应商旧到期日写短

### 用量字段

#### `data_used`

- 含义：累计已用流量
- 写入方：同步任务、供应商回调修正
- 读取方：卡片列表、详情、流量池统计、仪表盘
- 高风险联动：
  - 影响超量判断、池统计、首页统计

#### `data_total`

- 含义：当前卡片可用总流量
- 写入方：入库、出库规格派生、供应商用量同步、后台补量、加油包、年包续费
- 读取方：卡片列表、详情、用量百分比、超量停卡、流量池统计、仪表盘
- 高风险联动：
  - 影响超量判断和展示口径
  - 年包流量跨月累计，续费时会追加新周期流量额度
  - 用量同步必须保护本地更大的年包 `data_total`，避免供应商旧套餐总量覆盖本地续费额度
  - 月包仍保留“至少不低于套餐规格流量”的展示/同步口径

#### `data_used_month`

- 含义：本月已用流量
- 写入方：同步任务
- 读取方：卡片展示、月度统计类逻辑
- 高风险联动：
  - 影响月度用量展示和告警

#### `addon_flow`

- 含义：当月补量
- 写入方：加油包/充值流程
- 读取方：卡片详情、流量池统计
- 高风险联动：
  - 影响总流量和剩余流量计算

#### `addon_flow_month`

- 含义：补量生效月份
- 写入方：补量流程
- 读取方：流量池、卡片用量计算
- 高风险联动：
  - 影响当月是否生效

#### `data_sync_at`

- 含义：最近同步时间
- 写入方：同步任务
- 读取方：卡详情、同步状态展示、排障
- 高风险联动：
  - 影响排查“数据是否新鲜”

### 状态字段

#### `status`

- 含义：卡片状态，如库存、沉默期、已激活、已停机
- 写入方：入库、出库、同步、停复机、回调、回收
- 读取方：几乎所有卡相关模块
- 高风险联动：
  - 是全项目最核心联动字段之一
  - 影响卡片列表、停复机、流量池、仪表盘、H5、回调

#### `suspend_type`

- 含义：停机类型，如手动、到期、池超限、单卡超量
- 写入方：停复机、流量池阈值、同步修正
- 读取方：卡详情、停复机日志、仪表盘
- 高风险联动：
  - 影响停机原因展示和自动恢复逻辑

#### `suspend_at`

- 含义：停机时间
- 写入方：停复机、阈值触发、回调修正
- 读取方：卡详情、停复机日志、排障
- 高风险联动：
  - 影响停机记录与展示

#### `suspend_reason`

- 含义：停机原因描述
- 写入方：停复机、阈值触发
- 读取方：卡片详情、日志、告警
- 高风险联动：
  - 影响排障时可读性和运营解释

### 流量池关联字段

#### `pool_id`

- 含义：所属流量池 ID
- 写入方：加卡入池、移池、回收
- 读取方：流量池详情、卡片列表、池统计
- 高风险联动：
  - 影响池内卡查询和停复机池级联动

#### `is_pool_member`

- 含义：是否属于流量池
- 写入方：入池、移池
- 读取方：卡片列表、组池逻辑
- 高风险联动：
  - 常和 `pool_id` 一起检查，不能只改一个

- 高风险联动：
  - 影响底层规格同步

#### `price_cost` / `price_sale`

- 含义：成本价 / 销售价
- 写入方：套餐管理
- 读取方：出库、利润展示、运营统计
- 高风险联动：
  - 影响出库金额和报表
