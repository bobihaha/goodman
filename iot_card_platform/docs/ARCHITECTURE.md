# 系统架构

## 整体架构

```
┌─────────────────────────────────────────────────────────────────┐
│                        物联网卡管理平台                           │
├─────────────────────────────────────────────────────────────────┤
│  前端层 (Vue3 + TypeScript)                                      │
│  ├── 超级管理员后台                                               │
│  ├── 用户/代理商后台                                              │
│  └── 子用户后台                                                   │
├─────────────────────────────────────────────────────────────────┤
│  API网关层 (FastAPI)                                             │
│  ├── 认证鉴权 (JWT)                                               │
│  ├── 权限控制 (RBAC)                                              │
│  └── 请求路由                                                     │
├─────────────────────────────────────────────────────────────────┤
│  业务服务层                                                       │
│  ├── 用户服务      ├── 卡片服务      ├── 套餐服务                  │
│  ├── 流量池服务    ├── 出入库服务    └── 供应商对接服务             │
├─────────────────────────────────────────────────────────────────┤
│  数据层                                                          │
│  ├── MySQL 8.x (主数据)                                          │
│  ├── Redis (缓存/会话)                                           │
│  └── 文件存储 (日志/导出)                                         │
├─────────────────────────────────────────────────────────────────┤
│  外部接口层                                                       │
│  └── 供应商 API (流量同步/停复机)                                 │
└─────────────────────────────────────────────────────────────────┘
```

## 前端架构

### 分层设计

```
视图层 (Views)
  ├── 登录页
  ├── 仪表盘
  ├── 用户管理
  ├── 卡片管理
  └── 流量池管理

组件层 (Components)
  ├── 布局组件 (Layout/Sidebar/Header)
  ├── 业务组件 (CardTable/PoolChart)
  └── 通用组件 (DataTable/StatusTag)

状态管理 (Pinia)
  ├── authStore (认证状态)
  ├── userStore (用户信息)
  └── cardStore (卡片数据)

路由层 (Vue Router)
  ├── 路由守卫 (权限校验)
  └── 动态路由 (按权限加载)

服务层 (API)
  ├── authApi
  ├── cardApi
  └── poolApi

工具层 (Utils)
  ├── request.ts (Axios封装)
  ├── permission.ts (权限判断)
  └── formatter.ts (数据格式化)
```

## 多租户架构

### 三级用户体系

```
Level 1: 超级管理员
  ├── 全平台管理
  ├── 创建/管理用户
  └── 超级登录用户账号

Level 2: 用户/代理商
  ├── 管理自己的卡片
  ├── 管理子用户
  └── 超级登录子用户账号

Level 3: 子用户
  ├── 查看被分配的卡片
  └── 无管理权限
```

### 数据隔离

- **物理隔离**：通过 `user_id` 和 `parent_id` 实现层级关系
- **权限隔离**：根据 `user_level` 动态显示菜单和功能
- **查询隔离**：SQL查询自动添加用户过滤条件

## 核心流程

### 卡片生命周期

```
采购入库 → 测试期 → 沉默期 → 激活使用 → 到期停卡 → 销卡
```

### 出入库流程

```
入库：Excel导入 → 关联供应商/套餐 → 设置生命周期日期 → 入库成功
出库：选择卡片 → 选择用户/套餐 → 确认出库 → 生成出库单
```

### 流量同步流程

```
定时任务 → 调用供应商API → 更新流量数据 → 检查状态转换 → 触发告警
```

## 技术选型

### 前端
- **框架**：Vue 3.4 (Composition API)
- **语言**：TypeScript 5.x
- **UI库**：Element Plus 2.5
- **状态管理**：Pinia 2.1
- **路由**：Vue Router 4.x
- **HTTP**：Axios 1.6
- **构建**：Vite 5.x

### 后端
- **框架**：FastAPI
- **ORM**：SQLAlchemy 2.x (异步)
- **数据库**：MySQL 8.4
- **缓存**：Redis
- **认证**：JWT (PyJWT)
- **任务调度**：APScheduler
- **日志**：Loguru

### 部署
- **容器化**：Docker + Docker Compose
- **反向代理**：Nginx
- **进程管理**：Supervisor / PM2
