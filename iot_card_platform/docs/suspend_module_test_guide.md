# 停卡管理模块快速测试指南

## 🚀 快速开始

### 步骤1：添加菜单到数据库

```bash
# 方式1：使用MySQL命令行
mysql -u root -p你的密码 iot_card_platform < sql/add_suspend_menus.sql

# 方式2：手动执行SQL（如果上面的命令失败）
# 打开 sql/add_suspend_menus.sql 文件
# 复制SQL语句到数据库管理工具（如Navicat、phpMyAdmin）中执行
```

### 步骤2：验证菜单是否添加成功

```sql
-- 查询停卡管理菜单
SELECT id, code, name, path, parent_id, sort 
FROM sys_menus 
WHERE code LIKE '%suspend%' 
ORDER BY parent_id, sort;

-- 应该看到4条记录：
-- 1. suspend (停卡管理) - 父菜单
-- 2. suspend_policy (停卡策略) - 子菜单
-- 3. suspend_logs (停卡记录) - 子菜单
-- 4. suspend_alerts (停卡告警) - 子菜单
```

### 步骤3：启动前端服务

```bash
cd frontend
npm run dev
```

### 步骤4：访问页面

打开浏览器访问：http://localhost:5173

登录后，在左侧菜单应该能看到"停卡管理"菜单。

## 🐛 常见问题

### 问题1：左侧菜单没有显示"停卡管理"

**原因**：菜单未添加到数据库

**解决方案**：
1. 检查数据库中是否有停卡管理菜单
2. 执行 `sql/add_suspend_menus.sql` 脚本
3. 刷新浏览器

### 问题2：点击菜单后页面空白

**原因**：路由配置问题或组件加载失败

**解决方案**：
1. 打开浏览器控制台查看错误信息
2. 检查路由配置是否正确
3. 检查组件文件是否存在

### 问题3：API调用失败

**原因**：后端API未实现

**解决方案**：
这是正常的，因为后端还未开发。前端会显示错误提示，但不影响页面展示和交互测试。

### 问题4：表格数据为空

**原因**：后端API未返回数据

**解决方案**：
这是正常的。可以检查：
1. 页面是否显示"暂无数据"的空状态
2. 加载动画是否正常
3. 错误提示是否友好
