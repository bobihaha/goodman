# 一期发布说明

## 背景

本次发布主要解决停复机规则被绕过的问题，并补齐“上级给下级后台补量”后的自动恢复闭环。

历史问题表现为：

- 卡片被人工停卡、单卡超量停卡、流量池超量停卡后
- 用户仍可在部分页面点击“复机”
- 前端直接调用或间接触发运营商激活接口
- 造成停卡规则被绕过

## 本次发布内容

### 1. 统一复机规则

- 所有复机入口统一走同一套后端规则
- 不再允许某个页面可复机、某个页面不可复机的分裂逻辑

### 2. 普通复机按停卡原因校验

- 人工停卡：普通复机不可恢复
- 到期停卡：普通复机不可恢复
- 单卡超量停卡：补量后才允许恢复
- 流量池超量停卡：池补量后才允许恢复

### 3. 新增强制复机

- 仅超级管理员可用
- 用于人工停卡、特殊场景的强制恢复

### 4. 新增后台补量

- 支持上级给下级非流量池卡后台补量
- 支持上级给下级流量池后台补量
- 不包含用户自助购买

### 5. 补量后自动重检

- 单卡补量后，系统自动重检该卡是否满足复机条件
- 流量池补量后，系统自动重检池内因 `pool_exceed` 停卡的卡片
- 满足条件则自动复机

### 6. 日志可追踪

- 卡片详情页可查看单卡补量日志
- 流量池详情页可查看流量池补量日志

### 7. 前端工程修复

- 清理历史 TypeScript 报错
- 前端全量构建已恢复可用

## 影响范围

### 后端

- 停复机服务
- 卡片批量复机接口
- 单卡补量接口
- 流量池补量接口
- 操作日志查询接口

### 前端

- 卡片列表
- 卡片详情
- 流量池列表
- 流量池详情
- 补量日志展示
- 批量操作弹窗

## 业务口径

本期能力定义为：

- 上级用户对下级用户后台补量
- 非用户自主购买
- 非商品化流量充值

二期再扩展：

- 用户自助购买单卡流量
- 用户自助购买流量池加油包
- 到期续费购买
- 商品、订单、支付链路

## 验收重点

- 人工停卡卡片无法普通复机
- 到期停卡卡片无法普通复机
- 单卡补量后可按规则恢复
- 流量池补量后池内停卡卡片可按规则恢复
- 强制复机仅超级管理员可见
- 卡片详情和流量池详情可查看补量日志
