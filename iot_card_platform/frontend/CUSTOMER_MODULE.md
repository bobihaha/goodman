# 客户管理模块开发文档

## 📋 模块概述

客户管理模块用于管理平台的客户（用户）信息，包括创建、编辑、删除、启用/禁用、重置密码等功能。

**开发时间**: 2026-02-09  
**开发状态**: ✅ 已完成  
**访问路径**: `/users`  
**菜单名称**: 客户管理

## 🎯 功能清单

### 1. 客户列表
- ✅ 分页展示客户列表
- ✅ 关键词搜索（账号/姓名/手机号）
- ✅ 状态筛选（启用/禁用）

### 2. 客户操作
- ✅ 新增客户

## 🔌 API接口

### 后端API端点

| 方法 | 端点 | 说明 |
|------|------|------|
| GET | `/api/v1/users` | 获取客户列表 |
| POST | `/api/v1/users` | 创建客户 |
| GET | `/api/v1/users/{user_id}` | 获取客户详情 |
| PUT | `/api/v1/users/{user_id}` | 更新客户信息 |
| DELETE | `/api/v1/users/{user_id}` | 删除客户 |
| PUT | `/api/v1/users/{user_id}/status` | 修改客户状态 |
| PUT | `/api/v1/users/{user_id}/password` | 重置客户密码 |

### 请求参数

#### 获取客户列表
```typescript
{
  page?: number          // 页码，默认1
  page_size?: number     // 每页数量，默认10
  keyword?: string       // 关键词搜索
  status?: 'enable' | 'disable'  // 状态筛选
}
```

#### 创建客户
```typescript
{
  name: string           // 姓名（必填）
  account: string        // 账号（必填）
  password: string       // 密码（必填）
  phone?: string         // 手机号（可选）
  email?: string         // 邮箱（可选）
  alert_notify?: {       // 告警通知设置
    sms: boolean
    email: boolean
  }
  quota?: {              // 配额设置
    max_cards: number
    max_sub_users: number
  }
  remark?: string        // 备注
  status?: 'enable' | 'disable'  // 状态
}
```

#### 更新客户
```typescript
{
  name?: string
  phone?: string
  email?: string
  alert_notify?: {
    sms: boolean
    email: boolean
  }
  quota?: {
    max_cards: number
    max_sub_users: number
  }
  remark?: string
  status?: 'enable' | 'disable'
}
```

## 💾 数据结构

### User 类型
```typescript
interface User {
  id: number
  account: string       // 账号
  name: string          // 姓名
  phone?: string        // 手机号
  email?: string        // 邮箱
  parent_id?: number    // 父级用户ID
  status: UserStatus    // 状态：enable/disable
  remark?: string       // 备注
  alert_notify?: {      // 告警通知设置
    sms: boolean
    email: boolean
  }
  quota?: {             // 配额设置
    max_cards: number
    max_sub_users: number
  }
  created_at: string
  updated_at?: string
}
```

## 📝 使用说明

### 1. 访问客户管理
登录后，点击左侧菜单"客户管理"即可进入。

### 2. 搜索客户
在搜索栏输入关键词（账号/姓名/手机号），点击"搜索"按钮。

### 3. 新增客户
1. 点击"新增用户"按钮
2. 填写客户信息（姓名、账号、密码为必填）
3. 设置配额和通知选项
4. 点击"确定"提交

### 4. 编辑客户
1. 点击客户行的"编辑"按钮
2. 修改客户信息（账号不可修改）
3. 点击"确定"保存

### 5. 重置密码
1. 点击客户行的"重置密码"按钮
2. 输入新密码并确认
3. 点击"确定"提交

### 6. 启用/禁用客户
1. 点击客户行的"启用"或"禁用"按钮
2. 确认操作
3. 状态立即生效

### 7. 删除客户
1. 点击客户行的"删除"按钮
2. 确认删除（此操作不可恢复）
3. 客户被删除
