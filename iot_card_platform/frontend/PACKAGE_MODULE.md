# 套餐管理模块开发文档

## 📋 模块概述

套餐管理模块包含两个子模块：
1. **底层套餐（供应商套餐）** - 管理从供应商采购的底层套餐
2. **销售套餐** - 管理面向客户的销售套餐，关联底层套餐并设置销售价格

## 📊 核心功能说明

### 1. 自动组流量池功能

**原理**：
- 底层套餐可以启用"自动组流量池"功能
- 相同 `package_id` 的卡片激活时会自动加入同一个流量池
- 流量池名称自动生成：`{运营商}-{流量大小}-{周期}-自动池-{日期}`

**使用场景**：
- 批量管理相同规格的卡片
- 自动化流量池管理
- 减少手动操作

### 2. 利润率计算

**公式**：
```
利润 = 销售价 - 成本价
利润率 = (利润 / 成本价) * 100%
```

**颜色标识**：
- 红色：利润率 < 0（亏损）
- 橙色：0 ≤ 利润率 < 10%（低利润）
- 绿色：利润率 ≥ 10%（正常）

### 3. 数据关联

**底层套餐 → 销售套餐**：
- 销售套餐必须关联一个底层套餐
- 销售价格不能低于成本价
- 继承底层套餐的运营商、流量规格、周期类型等信息

**底层套餐 → 供应商**：
- 底层套餐必须关联一个供应商
- 记录采购来源
