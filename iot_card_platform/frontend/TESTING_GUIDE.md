## 🚀 启动项目

### 1. 启动后端
```bash
cd backend
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

### 2. 启动前端
```bash
cd frontend
npm run dev
```

## 🐛 常见问题排查

### 1. 批量查询失败
- 检查后端API是否正常运行
- 检查网络请求是否成功（F12 -> Network）
- 检查后端日志是否有错误

### 2. 用量百分比显示异常
- 检查 `data_used` 和 `data_total` 字段是否有值
- 检查计算公式是否正确
- 检查是否有除零错误

### 3. 批量操作无响应
- 检查是否已选择卡片
- 检查后端API是否返回正确的响应
- 检查是否有权限限制

### 4. 导出功能失败
- 检查浏览器是否允许下载
- 检查后端是否返回Blob数据
- 检查文件名是否合法
